# cryptoalert-privacy

Politique de confidentialité de l'application Android **CryptoAlert**, publiée
par GitHub Pages. C'est l'adresse que demande le Play Console.

Le dépôt ne contient qu'une page : `index.html`, en français et en anglais.

## Mettre à jour

La source est `docs/index.html` dans le dépôt de l'application. On modifie
**là-bas**, puis on recopie ici et on pousse. Toute modification doit aussi
mettre à jour la date en haut de chaque version linguistique, et rester
d'accord avec `PRIVACY.md`, le texte de référence.

## Activer la publication

Dans *Settings* du dépôt, section *Pages* : source **Deploy from a branch**,
branche `main`, dossier `/ (root)`. La page est servie quelques minutes plus
tard.
